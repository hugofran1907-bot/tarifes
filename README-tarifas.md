# Tarifas — Servicios Web

Página única (`tarifas.html`), independiente del portfolio. Mismo tipo de despliegue: solo necesitas subir el archivo, no depende de nada externo salvo Google Fonts.

## Opción A — Netlify Drop (más rápido, sin cuenta)

1. Abre [app.netlify.com/drop](https://app.netlify.com/drop).
2. Arrastra `tarifas.html` (puedes renombrarlo a `index.html` antes de subirlo si quieres que sea la portada del sitio).
3. Te da un link público al instante, sin login para quien lo abra.

## Opción B — GitHub Pages

1. Crea un repo público nuevo, ej. `Tarifas`.
2. Sube `tarifas.html` a la raíz (si quieres que se vea directamente en la URL principal, renómbralo a `index.html` al subirlo).
3. Ve a **Settings → Pages** del repo.
4. En "Source" elige la rama `main` y carpeta `/ (root)`. Guarda.
5. En 1-2 minutos queda publicado, accesible sin sesión para cualquiera.

## Nota

Este archivo es independiente del portfolio (`index.html` de las 9 webs) — no están enlazados entre sí, como pediste.
